# Titanic Survival Prediction

## Overview

A machine learning project that predicts whether a Titanic passenger survived based on passenger characteristics.

## Features

- Passenger class
- Sex
- Age
- Fare

## Machine Learning

Models evaluated:

- Logistic Regression
- Decision Tree
- Random Forest

The final Random Forest model was tuned using GridSearchCV with 5-fold cross-validation.

## Technologies

- Python
- pandas
- NumPy
- scikit-learn
- Matplotlib
- Jupyter Notebook

## Workflow

1. Load and explore the data
2. Select features
3. Handle missing values
4. Encode categorical data
5. Split training and test data
6. Train multiple models
7. Compare model performance
8. Tune Random Forest hyperparameters
9. Evaluate the final model
10. Make predictions on new passengers
